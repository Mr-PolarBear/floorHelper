# SillyTavern-FloorNav (楼层导航与超长楼层收起插件)

一个专为 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 打造的轻量级体验增强插件。解决长文本聊天中频繁滑动翻页、回溯前文困难的痛点。

---

## ✨ 核心特性

1. **📏 超长楼层智能折叠 (Collapse Long Floors)**
   - **智能检测**：仅当某楼层正文高度超过设定阈值（默认 300px）时，自动在该楼底部出现居中的「收起楼层」按钮。
   - **毫秒级实时响应**：在设置面板中拖动收起高度滑块时，页面所有楼层高度**立即实时联动变化**，无需刷新。
   - **平滑渐变截断**：收起后保留设定高度，底部带有丝滑的半透明渐变遮罩，只露出前几行正文，极大缩短翻页距离。
   - **无缝切换**：随时点击「展开楼层」恢复原状，支持重新收起。
   - **自适应多种场景**：支持左右滑动（Swipe）切换回复，新生成的长回复或带图片的楼层均能即时检测。

2. **🤖 智能历史自动收起（支持自定义保留最新楼层）**
   - **从倒数第 N 楼生效（默认 N=2）**：
     - **最新楼层展开**：AI 当前最新的回复和正在交互的内容保持完整展开，不影响当前阅读。
     - **旧回复自动收起**：当产生新一轮对话（AI 回复不再是最后一楼时），该超长历史楼层会自动收起！
     - 用户可在设置中自定义从倒数第几楼开始生效（如设为 2 表示仅倒数第 1 楼展开，历史长楼全部自动收起）。

3. **🏷️ AI 标签完整性检查 (Tag Integrity Inspector)**
   - **智能检测**：支持检查 AI 输出中是否包含并完整闭合特定 XML/HTML 标签（如 `<text>...</text>`, `<a>...</a>`, `<b>...</b>`, `<think>...</think>` 等）。
   - **红色警示提醒**：
     - **长楼层**：在折叠/展开按钮旁边显示红色发光提醒徽章（例如：`⚠️ 缺少 </text> 闭合标签`）；
     - **短楼层**：即使楼层未超高（无折叠按钮），只要标签不完整，也会在楼层底部居中醒目显示红色异常提醒徽章；
     - **导航面板联动**：在“跳转”列表中对应楼层旁同步标红 `[⚠️ 缺少 </text>]`，并支持在搜索栏中输入 `缺少` 或标签名快速筛选定位问题楼层。
   - **模式支持**：
     - **模式 B：强制必填模式（默认）**：要求每条 AI 回复必须包含所配置的标签，且必须成对闭合；
     - **模式 A：成对闭合模式**：若 AI 回复中出现了该标签，则必须完整闭合；若未出现则不强制报错。
   - **多标签与简单格式**：配置框支持自由输入简单格式如 `<text>, <a>, <b>` 或 `text, a, b`，自动解析校验。

4. **🚀 输入区悬浮工具栏 (Floating Toolbar & Floor Navigator)**
   - **紧凑悬浮栏**：在右侧输入区（`#form_sheld`）上方悬浮一个极简小巧的工具栏，完全避开下方分支切换箭头：
     - **⬇️ 直达最新楼头部**：点击向下的箭头，聊天窗口立即平滑滚动并对齐到最新消息的开头（而非滚到尾部），方便从头阅读！
     - **📑 楼层快速跳转**：点击「跳转」小胶囊按钮，呼出全楼层缩略导航面板。
   - **缩略列表**：点击弹出毛玻璃半透明导航面板，列出当前对话的所有楼层：
     - 显示楼层编号（#1, #2...）
     - 发送者身份标签（用户 / AI / 系统）
     - **正文前 20 字纯文本预览**（自动过滤 Markdown 语法和代码块）。
   - **平滑定位与发光高亮**：点击任意楼层条目，聊天窗口将平滑滚动至对应楼层，并带有淡金色发光脉冲光圈，一眼看清定位位置。
   - **快捷工具**：
     - ⬆️ 一键回到顶部（第 1 楼）
     - ⬇️ 一键回到底部（最新楼）
     - 🗜️ 一键全部收起 / 全部展开
     - 🔍 实时输入关键字搜索楼层内容或发送者

5. **⚙️ 完备的设置选项**
   - 在 SillyTavern 的「扩展设置 (Extensions)」抽屉中提供可视化面板：
     - 开关：启用超长楼层收起
     - 滑块：收起触发高度阈值 (150px ~ 800px，实时调节实时生效)
     - 开关：是否自动收起超长楼层
     - 输入框：从倒数第 N 楼开始自动收起 (默认 2)
     - 开关：启用输入区悬浮跳转按钮
     - 滑块：楼层列表预览字数 (10 ~ 60 字，默认 20 字)
     - 开关：启用标签检查与红色异常提醒
     - 输入框：检查的标签列表 (例如 `<text>, <a>, <b>`)
     - 下拉框：检查模式 (模式 B: 强制必填 / 模式 A: 成对闭合)
     - 开关：仅检查 AI 角色回复
     - 按钮：显式保存并立即应用设置（搭配双重持久化保证）

## 📦 如何安装与分享给他人

### 方式一：通过 Git URL 一键安装（推荐）

1. 打开 SillyTavern 网页；
2. 点击顶部导航栏的 **扩展图标 (Extensions)**（立方体形状图标）；
3. 点击 **「Install extension / 安装扩展」** 按钮；
4. 在弹出的输入框中粘贴 Git 仓库 URL：
   ```
   https://github.com/Mr-PolarBear/floorHelper.git
   ```
5. 点击安装，SillyTavern 会自动下载并加载插件，无需重启！

### 方式二：手动安装

1. 下载或解压本插件文件夹到 SillyTavern 的第三方扩展目录下：
   ```
   SillyTavern/public/scripts/extensions/third-party/SillyTavern-FloorNav/
   ```
2. 确保文件夹内包含以下文件：
   - `manifest.json`
   - `index.js`
   - `style.css`
   - `settings.html`
3. 刷新 SillyTavern 页面即可生效。
